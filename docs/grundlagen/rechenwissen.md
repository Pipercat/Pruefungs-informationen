# Rechenwissen

## Einheiten

- 1 Byte = 8 Bit
- Netzwerkgeschwindigkeit meist in bit/s, Dateigröße meist in Byte
- kB/MB/GB verwenden 1000er-Schritte; KiB/MiB/GiB 1024er-Schritte
- Ein Hex-Zeichen entspricht 4 Bit

Immer das in der Aufgabe vorgegebene Einheitensystem verwenden.

## Formeln

- Datenmenge = Datenrate × Zeit
- Übertragungszeit = Datenmenge / Datenrate
- Auslastung = tatsächliche Nutzung / maximale Kapazität × 100 %
- Verfügbarkeit = Betriebszeit / Gesamtzeit × 100 %
- Gewinn = Erlöse − Kosten
- Wirtschaftlichkeit = Ertrag / Aufwand
- Produktivität = Output / Input
- Rentabilität = Gewinn / eingesetztes Kapital × 100 %

## Vorgehen

Gegebenes und Gesuchtes markieren, Einheiten vereinheitlichen, Formel notieren, Werte einsetzen, Ergebnis mit Einheit angeben und plausibilisieren. Protokolloverhead nur berücksichtigen, wenn er angegeben oder ausdrücklich verlangt wird.
