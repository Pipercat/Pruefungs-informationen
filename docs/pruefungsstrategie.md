# Prüfungsstrategie und Lernplan

## Prioritäten

**Zuerst sicher beherrschen:** IPv4/IPv6 und Subnetting, Ethernet/MAC/ARP/ICMP, TCP/UDP und Ports, VLAN/Switching/Routing, DHCP/DNS sowie systematische Fehlersuche.

**Danach vertiefen:** Firewall und Segmentierung, Authentifizierung und Zertifikate, IT/OT-Systeme, Sensoren/Aktoren/Gateways, Monitoring, Redundanz, Backup und Restore.

**Regelmäßig üben:** REST/HTTP/JSON/MQTT/SSH, Bandbreiten- und Speicherrechnungen, Variantenvergleiche, WiSo und Aufgaben aus früheren Prüfungen.

## Operatoren richtig bedienen

| Operator | Erwartete Antwort |
| --- | --- |
| nennen | präzise Begriffe ohne lange Erklärung |
| beschreiben | Sachverhalt strukturiert wiedergeben |
| erklären/erläutern | Zusammenhang, Ursache und Beispiel oder Folge |
| begründen | Aussage mit Argument und Bezug zur Situation |
| beurteilen | Kriterien anwenden, abwägen und Urteil formulieren |
| berechnen | Formel, eingesetzte Werte, Rechenweg, Ergebnis und Einheit |

## Antwortschemata

- **Diagnose:** Sollzustand → Istzustand → Hypothese → gezielter Test → Ergebnis → Maßnahme → Funktionskontrolle → Dokumentation.
- **Variantenentscheidung:** Anforderung → Optionen → Kriterien → Vor-/Nachteile → Entscheidung mit Szenariobezug.
- **Materialauswertung:** Aussage → Begründung → Materialbezug → Folge. Bei einer Stellungnahme beide Seiten gewichten und mit einem Urteil enden.

## Selbstkontrolle

- [ ] IPv4-Subnetze ohne Hilfe berechnen
- [ ] IPv6-Adresstypen, `/64`, SLAAC und NDP erklären
- [ ] Tagged/Untagged, VLAN und Inter-VLAN-Routing erklären
- [ ] DHCP-DORA, DNS und TCP-Handshake erkennen
- [ ] Routing- und Firewallregeln lesen
- [ ] Paketmitschnitte und Logs systematisch auswerten
- [ ] IT/OT-Prozessebenen und Datenflüsse darstellen
- [ ] Bandbreite, Speicher, Auslastung und Verfügbarkeit berechnen
- [ ] Backup, RAID, Redundanz, RPO und RTO unterscheiden
- [ ] WiSo-Grundbegriffe und kaufmännische Rechnungen anwenden
- [ ] Projektziel, Architektur, Alternativen, Tests und Eigenanteil erklären
